🚀 Getting Started

1. Download or clone this repository.
2. Ensure "index.html" is in the root directory.
3. Keep all required images and assets in their correct folders.
4. Upload the project files to your GitHub repository.
5. Open Settings → Pages.
6. Select the "main" branch and "/(root)" folder, then save.
7. Wait for GitHub Pages to publish your website.
